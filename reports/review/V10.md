// pure-local contract (`store.ts:makeMove` isAnonymous guard)

**建议 fix**（下波 docs/qa patch）：

```diff
- // pure-local contract (`store.ts:makeMove` isAnonymous guard)
- // skips localStorage writes for anonymous offline play, so a
- // name is required to exercise the offline accumulation path.
+ // W2 pure-local contract: seeding the player name keeps the
+ // probe focused on the offline-mode flow; W4 D-1 made offline
+ // write localStorage unconditionally (no name required).
```

**为何不阻塞 ACCEPT**：probe 行为正确；仅 prose 漂移。
