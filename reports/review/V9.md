## 6. 终判理由

两 plan 的核心契约已完整落地：

1. **API 契约**：4 个 `/api/rooms/*` 端点是唯一 API surface（旧 4 个端点全删，攻击向量全 422/404/409 严控）；RFC 9457 problem+json 错误形态稳定；whitelist（trim + 1-24 字符 + 禁控制字符）是 service-side 单一真源。
2. **DB 契约**：单表 `game_stats`（`room TEXT UNIQUE`）+ 清空式 reconcile（列集不符即 DROP 重建，D-4 许可）+ legacy 数据保留已弃（D-4 决议）。
3. **客户端契约**：Zustand store 单例 + 8s AbortController timeout + `roomName` 字段；localStorage 单 key（`ttt.room.name.v1`）；legacy `ttt.player.name.v1` 启动期清零不迁移。
4. **W4 语义变更**：offline 分支 `makeMove` 摘 `isAnonymous` 早退守卫，online 分支守卫保留（F4）；本地账本无条件累加；HomeDialogMount 触发条件 `pending > declined && pending > 0` 自然覆盖匿名；SyncConfirmDialog 收名合并 = postRoomSession + postMerge + 清本地 + baseline=0。
5. **UI 红线**：用户可见文案零「玩家名/注册/登录」（grep 零命中）；首页零 `/api/*` 请求（A1 红线三层验证：anonymous / named / focus×3）；HomeStatsEntry 纯 Link 零副作用。
6. **探针矩阵**：A1-A12 主线探针全绿（one-identity-qa 10 / home-return-qa 9 / offline-mode-qa 9 / offline-qa 5 / offline-result-qa 5 / one-screen-qa 12 / visual-qa 12）；自写对抗 14/15 DEFENDED（A9 实为 whitelist 防御成功非漏洞）。
